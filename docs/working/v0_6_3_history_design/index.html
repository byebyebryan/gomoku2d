About this study

Recommendation, content boundaries and sources

Starting recommendation: A for browsing the history, with B available when following one screen. C gives quicker repeated comparison, but takes width from the captures and needs more navigation on a phone.

The milestone roster and summaries are proposals drawn from the changelog. Source-diff review still decides which patches need their own entry. Capture coverage is incomplete; empty panels are deliberate placeholders, never another version's image.

The Public player example uses a 0.6.1-era development capture and the exact 0.6.2 release reference. Their synthetic content differs, so they illustrate this layout rather than establish a standardized release comparison. The older capture's exact commit is not established here.

Home, Match, Replay and Profile use the qualified 0.2.4/0.6.2 retrospective pilot where available. Those are the only recreated historical release captures included. Portrait references are generic viewports; they do not establish phone calibration.

Shared fonts, tokens and control styles are copied from the current app. Captured PNGs retain original bytes. No application integration, cloud access or new historical capture run is part of this study.
